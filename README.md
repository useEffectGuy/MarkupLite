# MarkupLite

微信公众号排版工具 - 轻量级、零依赖、所见即所得（大体还行，模板这块一致跟平台有些不兼容，没想到办法，只能复制粘贴，取消背景色）

## 功能特点

- 🖍️ **所见即所得编辑** - 左侧编辑器，右侧手机预览
- 📋 **丰富模板库** - 30+精美组件，包括基础元素、标题系统、内容样式、提示卡片、时间进度、底部区域、排版主题等
- 📱 **微信公众号兼容** - 所有样式经过优化，复制即可直接粘贴使用
- 🛠 **完整工具链** - 加粗、斜体、标题、列表、对齐、缩进等格式化工具
- 📜 **版本历史** - 自动保存，支持30个版本快照
- 🌓 **暗色模式** - 支持深色主题切换
- ⌨️ **快捷键支持** - Ctrl+S 保存，Ctrl+P 命令面板，Ctrl+Shift+C 复制到公众号

## 快速开始

### 方式一：启动脚本（推荐）

双击 `启动MarkupLite.bat` 文件即可启动本地服务器。

### 方式二：命令行启动

```bash
cd MarkupLite
python -m http.server 9090
```

然后在浏览器中访问：`http://localhost:9090/MarkupLite.html`

### 方式三：直接打开

直接用浏览器打开 `MarkupLite.html` 文件即可使用（部分功能可能受限）。

## 模板库分类

### 基础元素
- 分隔线、精美分割线、关注引导、往期回顾、文末二维码

### 标题系统
- 主标题、副标题、小标题

### 内容样式
- 强调标记、引用卡片、金句引用

### 提示卡片
- 提示卡片、警告卡片、通用卡片

### 时间进度
- 时间轴、进度条

### 底部区域
- 引导关注、打赏区域、二维码区域、留言组件、阅读原文

### 排版主题
- 悬疑标准叙事、悬疑紧凑快切、武侠疏朗古卷、悬疑档案碎片、武侠快意恩仇、仙侠空灵意象

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + S` | 导出HTML |
| `Ctrl + P` | 打开命令面板 |
| `Ctrl + Shift + C` | 复制到公众号 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |

## 技术栈

- **纯 HTML/CSS/JavaScript** - 零依赖，无需构建工具
- **Python HTTP Server** - 本地开发服务器（可选）
- **LocalStorage** - 版本历史本地存储
